# Initial Database Entities

## 1. Users
Stores information about authorized users who access the dashboard.

## 2. Security Events
Stores simulated security events such as failed logins,
successful logins, suspicious access attempts and other
predefined activities.

## 3. Detection Rules
Stores predefined rules used to identify suspicious activity
patterns.

## 4. Alerts
Stores alerts generated when detection conditions are triggered.

## 5. Incidents
Stores security incidents that require investigation,
classification, tracking and resolution.
