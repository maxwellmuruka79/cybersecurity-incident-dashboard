# Incident Management Workflow

1. Security Event
Security events are generated or recorded by the system.

2. Detection
Predefined detection rules analyse selected event patterns.

3. Alert
When a detection condition is met, the system generates an alert.

4. Incident Creation
An alert requiring investigation can result in an incident.

5. Classification
The incident is assigned a category, severity and status.

6. Investigation
The user reviews the available event information and records
investigation notes.

7. Resolution
The incident is marked as resolved after the investigation.

8. Closure
The incident is closed and retained as part of the incident history.
