  **Functional requirements**
  
FR-01 — User Authentication
The system shall allow authorized users to log in and access the dashboard.

FR-02 — Dashboard
The system shall display security-event and incident summaries,
statistics, and recent activity.

FR-03 — Event Management
The system shall store and display security events.

FR-04 — Detection
The system shall apply predefined rules to identify selected
suspicious activity patterns.

FR-05 — Incident Management
The system shall allow users to create, view, update, classify,
and resolve incidents.

FR-06 — Filtering and Search
The system shall allow users to filter and search events and incidents.

FR-07 — Alerts
The system shall display alerts when selected detection conditions
are met.

FR-08 — Reporting
The system shall provide basic summaries and reports of incidents
and events.
