# System Modules

## 1. Authentication
Handles user login and access to the dashboard.

## 2. Dashboard
Displays security-event and incident statistics, summaries,
and recent activity.

## 3. Security Events
Stores and displays recorded security events.

## 4. Detection
Applies predefined rules to identify suspicious activity.

## 5. Alerts
Displays alerts generated when detection conditions are met.

## 6. Incident Management
Allows users to create, view, update, classify,
investigate, and resolve incidents.

## 7. Search and Filtering
Allows users to search and filter events and incidents.

## 8. Reporting
Provides basic summaries and reports of events and incidents.
